# TURTLE

TURTLE은 OpenSSL과 wolfSSL의 공개 입출력 경계를 바탕으로 TLS 1.3 전체 핸드셰이크를 같은 기준에서 비교하는 C/C++ 벤치마크 프레임워크를 목표로 합니다. TURTLE은 약어가 아닌 프로젝트 이름입니다.

이 작업 공간은 설계부터 새로 시작합니다. 먼저 연구자가 제공할 입력, 측정 구간의 시작과 끝, 한 실행에서 받는 결과를 함께 정합니다. 공통 API, 구간 분류 방법, 전송 프레임의 필요성과 사건 형식은 아직 확정하지 않았습니다.

C++20, CMake, Ninja를 사용하며 클라이언트와 서버의 측정 결과를 구별합니다. 이전 실험 결과는 설계의 참고 근거로 활용합니다.
