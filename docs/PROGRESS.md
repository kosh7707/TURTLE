# 구현 상태와 남은 범위

이 문서는 최초 작업 목록 M0~M14를 현재 코드에 대응시킵니다. 구체적인 통과 횟수, 과거 실패와 수리 근거는 [검증 기록](validation.md)에만 보존합니다.

| 작업 | 상태 | 현재 경계 |
|---|---|---|
| M0 저장소·규칙 | 완료 | C++20·CMake·Ninja, 모듈별 소스, 별도 시험 빌드, 확인 스크립트와 공개 계약을 갖췄습니다. |
| M1 새 역할 프로세스 | 완료 | 표본마다 서버와 클라이언트를 새 프로세스로 만들고, 준비·측정 연결과 소켓 실제값을 구별해 기록합니다. |
| M2 제어·원자료 | 완료 | 측정 TCP와 별도인 준비 통로, 고정 기록 버퍼, 역할별 JSONL·스트림·키 로그·무효 이유를 남깁니다. |
| M3 컨텍스트 | 제한적 완료 | 역할별 입력을 실행 시작에 한 번 읽고 표본마다 같은 저장본을 전달합니다. mock 저장·복원은 확인했지만 세 실제 TLS 어댑터의 비어 있지 않은 상태와 세션 재개는 지원하지 않습니다. |
| M4 인증서 | 완료 | ECDSA·RSA2048·Ed25519 잎, 체인 길이 1~3의 시험 PKI를 만들고 공통 유효 기간으로 정상 검증합니다. 호스트 시계를 바꾸는 시험은 아닙니다. |
| M5 OpenSSL 상호운용 | 완료 | 수정하지 않은 OpenSSL CLI와 세 어댑터의 클라이언트·서버, 서버 인증·상호 인증을 공개 ABI로 연결했습니다. TLS shutdown alert 완전성이나 성능을 증명하지 않습니다. |
| M6 비차단 송수신 | 완료 | 콜백 경로의 스트림·I/O·커널 수신 관측과 OpenSSL 라이브러리 직접 소켓 경로의 제한된 기능 실행을 구별합니다. wolfSSL·Mbed TLS의 라이브러리 직접 소켓 경로는 지원하지 않습니다. |
| M7 계측 영향 | 제한적 완료 | 채널 관측자 켬/끔과 양 역할의 공통 호출 경계를 구현했습니다. 그 차이는 전체 계측 비용의 상한·하한이나 무계측 기준선이 아닙니다. |
| M8 해독 | 완료 | `TLS_AES_128_GCM_SHA256`의 방향별 스트림을 키 로그로 해독합니다. 다른 암호군은 범위 밖입니다. |
| M9 세 어댑터 | 완료 | 고정 판 OpenSSL·wolfSSL·Mbed TLS의 공통 프로필과 모든 클라이언트/서버 조합을 지원합니다. |
| M10 검증 실험 | 제한적 완료 | 원자료 재계산, 구간 합, 바이트 대응, 해독과 정상 기능 반복을 자동화했습니다. eBPF·NIC 시각·완전한 계측 정확도 대조는 지원하지 않습니다. |
| M11 요약·재현 | 완료 | StQ, 분포, 독립 부트스트랩, 묶음 기록, 순서 무작위화와 의존성 고정 도구를 제공합니다. |
| M12 연구 기법 재측정 | 준비만 완료 | 인증서·티켓 설정을 바꿔 실행할 수 있지만 실제 인증서 압축·생략·캐싱 기법과 원 논문 재현은 구현하지 않았습니다. |
| M13 모의 CA | 범위 고정 | 합성 조회, 별도 모의 CA, 서비스 원자료와 시도 원장을 구현했습니다. 조회 객체는 캐시에 소비되지만 수정하지 않은 TLS 인증서 입력을 대체하지 않습니다. |
| M14 격리 netem | 범위 고정 | 조회 또는 순수 TLS를 소유한 사용자·네트워크 이름공간에서 실행하고 조건·무결성 근거를 기록합니다. 현재 [문서화한 조건](mock-ca.md)을 확장하거나 다시 설계하지 않습니다. |

## 현재 완료 경계

- 정상 인증서 기반 TLS 1.3 전체 핸드셰이크와 암호화된 핑퐁을 같은 공개 ABI와 원자료 형식으로 실행합니다.
- 클라이언트와 서버의 측정 구간, 관측 가능성, 측정 계약 개정값과 성능 카운터 상태를 분리해 보고합니다.
- `director.cpp`, `role_runtime.cpp`, `endpoint_protocol.cpp`, `lookup_runtime.cpp`로 실행 책임을 나누고 `model`·`record`·`report` 값과 서비스를 별도 파일에 둡니다.
- 실제 TLS, 정적 검사와 보존 원자료 재생의 근거는 [검증 기록](validation.md)에 있습니다. 기능 시험은 성능 순위나 외부 장비의 결과를 증명하지 않습니다.

## 별도 결정이 필요한 미지원 범위

아래 항목은 이번 목표의 남은 필수 작업이 아닙니다. 필요하다면 측정 정의와 실험 설계를 먼저 별도로 결정해야 합니다.

- 실제 인증서 압축·생략·캐싱 기법과 관련 논문의 재현
- 원격 두 호스트 실행기와 호스트 간 시계·네트워크·하드웨어 통제
- 서버의 계측 없는 외부 기준선과 전체 계측 비용을 추정하는 방법
- 스택 최고 사용량, 커널 송신 시각, NIC 하드웨어 시각, eBPF 또는 일반 패킷 캡처
- 현재 고정한 모의 CA·조회·netem 범위를 넘는 손실 조건과 운영 CA 기능

현재는 한 호스트의 로컬 TCP만 사용합니다. WSL에서 얻은 기능·구조 진단값은 물리 장비 성능 결론으로 사용하지 않습니다.
