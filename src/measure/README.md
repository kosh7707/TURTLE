# 측정 부품

역할 프로세스의 TLS 작업 스레드가 `Meter`를 만들고 같은 스레드에서 사용합니다. 성능 카운터는 생성한 스레드의 사용자 공간 실행만 셉니다. 두 카운터를 하나의 그룹으로 읽은 다음 스레드 CPU 시각, 단조 시각 순서로 읽습니다. 그룹을 열 수 없거나 읽지 못하면 해당 사건의 카운터 값은 빈 값입니다. 카운터 값을 비례 확대하지 않으며, 실행 가능 시간과 실제 실행 시간을 함께 남겨 다중화 여부를 판단하게 합니다.

메모리 모드에서만 할당 함수가 요청한 바이트를 셉니다. 힙 관리용 머리글, 실제 할당기의 정렬 여유 공간, 프레임워크의 자체 할당은 포함하지 않습니다. 성공한 재할당은 이전 요청의 해제 한 번과 새 크기의 할당 한 번으로 셉니다. 재할당 내부에서 잠깐 생기는 두 버퍼의 실제 최고 점유량까지 관측하는 것은 아닙니다. 실패한 재할당은 기존 기록과 메모리를 유지합니다. 크기 0으로 재할당하면 해제합니다.

할당 함수 묶음과 그 함수로 만든 모든 메모리는 소유한 `Meter`보다 먼저 사용을 끝내야 합니다. 서로 다른 측정기의 메모리를 섞어 해제하지 않습니다. 이 부품은 단일 TLS 작업 스레드를 위한 것이며 여러 스레드에서 동시에 할당하는 구현은 지원하지 않습니다. 시간 모드와 추적 모드의 할당 함수는 일반 할당기를 그대로 호출하며 힙 값은 빈 값입니다.

사건을 읽을 때 구간 최고치를 반환하고 현재 살아 있는 바이트로 다음 구간을 시작합니다. `read(false)`와 보정은 구간 최고치를 초기화하지 않습니다. 보정은 연속한 두 계측 읽기의 차이이며, 기록 버퍼에 사건을 넣는 비용이나 실제 통신에 미치는 영향까지 포함하지 않습니다. 이 차이는 결과를 해석할 때 별도로 밝혀야 합니다.

안전하게 분리한 스택의 최고 사용량 계측은 아직 없으므로 스택은 미지원입니다. 실행 중인 스택을 칠하지 않습니다. 하드웨어 시각, 시스템 호출 추적, 패킷 캡처도 이 부품이 제공한다고 보고하지 않습니다.
