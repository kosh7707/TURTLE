# 환경 확인 부품

커널, CPU 모델, 컴파일러, 허용된 CPU, 물리 코어 대표 CPU, 주파수 정책, 자동 클럭 상승 상태를 읽습니다. 장비 설정은 바꾸지 않습니다. 환경 해시는 정적인 관측값으로 만들며 순간 부하 평균은 제외합니다. 부하 평균은 별도 값입니다.

물리 코어는 시스템이 제공하는 소켓 번호와 코어 번호의 쌍으로 구별합니다. 자동 선택은 확인된 물리 코어에서 지휘 프로세스, 클라이언트, 서버를 하나씩 고릅니다. 세 코어를 확보하지 못하거나 명시한 CPU가 겹치면 예외를 반환합니다. 고정을 끄는 선택은 호출자가 명시해야 하며 논리 CPU로 몰래 대체하지 않습니다.

환경 확인과 CPU 선택은 지휘 프로세스의 CPU 고정 전에 수행해야 합니다. 각 역할 프로세스를 만든 다음 각자 고정해야 합니다. 먼저 지휘 프로세스를 고정한 뒤 그 좁은 허용 집합을 자식에게 물려주면 다른 CPU로 고정할 수 없습니다.

현재 고정 마스크는 리눅스의 `CPU_SETSIZE` 범위입니다. 더 큰 마스크가 필요한 장비에서 확인이 실패하면 경고를 남기고 자동 선택도 실패합니다. 주파수 정책이나 자동 상승 상태를 읽지 못하면 모름으로 남깁니다. 시계 동기화와 다른 프로그램의 부하는 통제하지 않습니다.
